CAM reference ​

Use CAM 1.4.0 with UI 1.1.0 for the current implementation. This is an experimental format. Earlier versions below document historical behavior; current software does not accept their manifests.

The current host returns a manifest URI and a SHA-256 digest of its exact bytes through camManifest(). The manifest also pins its protocol, ABI and UI resources. Do not use the older Keccak-256 manifest convention.

Which reference do I need?

  • Discover and authenticate an application.
  • Interpret routes and namespaces.
  • Interpret the UI vocabulary.
  • Understand the viewer's integrity warnings.
  • Build a workflow with the worked guide.
