Contract-defined workflows

A contract publishes a workflow description. A generic viewer or agent interprets it; business contracts enforce the rules. Start with the task you need—not with deployment internals.

Start

Understand what runs where, then try Pay-to-Play with a local test wallet.

Use

Open an existing app, connect a wallet and check the result. The instance directory lists published coordinates.

Build

Edit and validate a workflow, or integrate without a browser. Begin with source setup.

Deploy

Host the viewer, deploy a new app, or update an existing publication. These are different tasks.
